# Kwizerana website design

## Existing identity
Preserve the established light lavender-white surface with purple structure, orange calls to action and an eggplant trust band. Visitors read service information in ordinary office or home lighting.

## Typography
Poppins headings, Figtree body, JetBrains Mono short labels. Reuse the existing font stack and fluid heading sizes.

## Layout and components
1080px maximum content width, 26px page gutters, responsive split hero, timeline, service comparison and native FAQ disclosures. Use the existing logo asset. Preserve the attached Concierge composition; add clear navigation between the two offerings.

## Colour and motion
The existing assets/css/kwizerana.css defines brand tokens. Preserve those identity choices. Use higher-contrast calls to action and visible focus states for new content. Respect reduced motion. No new generated images are needed for this integration.
